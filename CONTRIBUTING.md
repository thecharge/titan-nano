# Contribute to Titan Nano

Contributions happen through [GitHub Issues](https://github.com/thecharge/titan-nano/issues). Share bug reports, feature proposals, questions and reproducible examples there. Maintainers review proposals and implement accepted changes. Pull requests are disabled for this repository.

## Report a bug

Search existing issues first. Include the Titan version, operating system, selected agent, exact command, expected result and observed result. Provide a small reproduction when possible. Remove credentials, personal data and private project content from logs and screenshots. The bug report template lists the details needed to investigate.

## Propose a feature

Describe the problem, your intended workflow and how you would recognize a successful result. Link related issues or OpenSpec requirements when available. Maintainers use OpenSpec to retain requirements, design decisions and verification evidence.

## Ask a question

Describe your goal, the command or workflow you tried and where you need help. Keep discussion about the same problem in its existing issue.

## Discuss security concerns

Follow the [security reporting guidance](SECURITY.md). Start with the affected component and impact. Keep credentials and sensitive reproduction details out of public issues.

## Develop locally

Read the [development guide](docs/development.md) and [development rules](DEV_RULES.md) before changing a local checkout. GitHub Actions is disabled. Repository verification runs locally through the normal checks and hooks.

The [Apache-2.0 license](LICENSE) describes use and redistribution rights. Issue submission follows the contribution terms in that license. Keep third-party material attributed and identify its source and applicable terms.
