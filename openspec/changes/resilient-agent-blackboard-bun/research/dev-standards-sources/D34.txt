Please describe. Currently, developers using Bun runtime cannot use StrykerJS for mutation testing their projects. Bun is a fast JavaScript runtime that's gaining popularity, but there's no official StrykerJS test runner plugin for it. This prevents the Bun community from benefiting from mutation testing, which is a crucial tool for ensuring test quality. Describe the solution you'd like I've developed a fully functional Bun test runner plugin for StrykerJS and would like to request its inclusion in the official @stryker-mutator scope. The plugin is currently published as stryker-mutator-bun-runner on NPM and implements all the necessary features: Full StrykerJS TestRunner interface implementation TypeScript & JSX support out of the box Smart coverage analysis with perTest coverage support Process pool for 2-3x faster execution Watch mode and snapshot testing support Source map support for accurate error reporting 97.91% code coverage with 264 tests 100% mutation score on the plugin itself Describe alternatives you've considered Keep as separate package : The plugin could remain as stryker-mutator-bun-runner , but this lacks the official support and trust that comes with the @stryker-mutator scope. Fork existing runner : Considered forking jest-runner or mocha-runner, but Bun has its own test runner with unique features that required a dedicated implementation. Wrapper approach : Tried creating a wrapper around existing runners, but this would lose Bun's performance benefits and native features. Additional context NPM Package : https://www.npmjs.com/package/stryker-mutator-bun-runner GitHub Repository : https://github.com/menoncello/stryker-mutator-bun-runner Current Version : 0.4.0 License : Apache-2.0 (same as StrykerJS) The plugin follows the same architecture as other official test runners like @stryker-mutator/jest-runner and @stryker-mutator/mocha-runner . I'm happy to: Transfer repository ownership to stryker-mutator organization Maintain the plugin as part of the ecosystem Adapt code to match any specific StrykerJS standards Implement additional features as requested Example configuration: { "testRunner" : " bun " , "plugins" : [ " stryker-mutator-bun-runner " ], "bun" : { "testFiles" : [ " **/*.test.ts " ], "timeout" : 30000 } } This would enable thousands of Bun users to adopt mutation testing in their projects! 👍 React with 👍 8 Reacted by Viktor Sokolov, Simon Owusu, Guilherme J.
